# Scripts

This directory groups standalone utilities by task. Run commands from the
repository root unless a subfolder README says otherwise.

## Available Tools

- `collect_safety_tscnet/`: run safety/performance evaluation for TSC-Net checkpoints.
- `compress_log/`: parse and compact copied evaluation logs.
- `plot_collision_curves/`: plot collision curves from embedded summary text.
- `plot_leader_set_distribution/`: plot stacked leader-set distribution bars from Excel.
- `plot_training_curves/`: plot reward and collision training curves across seeds/methods.
- `run_multi_seeds/`: launch repeated training runs with different seeds.
- `to_excel/`: convert pasted evaluation logs into spreadsheet-style summaries.
