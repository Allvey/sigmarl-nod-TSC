# compress_log

Parses a pasted evaluation log block and prints a compact summary table.

## Inputs

The input log text is embedded in `compress_log.py` as the `raw_text` string.
Replace it with the log content you want to summarize.

## Outputs

This script prints the compact summary to stdout. It does not create output
files by default.

## Usage

From the repository root:

```bash
python scripts/compress_log/compress_log.py
```
