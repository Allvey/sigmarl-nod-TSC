# plot_collision_curves

Plots collision-rate comparison curves from summary log text.

## Inputs

The input log text is currently embedded in `plot_collision_curves.py` as the
`raw_text` string. Replace that string when plotting a new set of results.

## Outputs

Generated plots are written under:

```text
scripts/plot_collision_curves/outputs/curve_plot/
```

## Usage

From the repository root:

```bash
python scripts/plot_collision_curves/plot_collision_curves.py
```
