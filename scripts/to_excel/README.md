# to_excel

Converts pasted evaluation summaries into tabular spreadsheet-style output and
figures.

## Inputs

The input evaluation log text is embedded in `to_excel.py`. Replace the log text
inside the script before running.

## Outputs

Default outputs are written under:

```text
scripts/to_excel/outputs/
```

This includes the generated Excel workbook and radar plots.

## Usage

From the repository root:

```bash
python scripts/to_excel/to_excel.py
```
